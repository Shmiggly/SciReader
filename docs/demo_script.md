**Opening the marimo notebook for the 2:35 segment.** In a terminal at the repo: `cd backend`, then `uv run marimo edit ../bench/analysis.py` (shows the cells and their outputs, which is what proves it's a marimo notebook; a browser tab opens at http://localhost:2718). For a cleaner app view: `uv run marimo run ../bench/analysis.py`. No install needed for viewers: `bench/analysis.html` (static export, refreshed from the current results). The charts are also in `bench/figures/` (faithfulness, units, units_heldout).

**Numbers to keep exact:** 220 equations, 24 papers; 61 → 89 % faithful (9B, judge-capable subset of 70); 4B with gate 90 %; gate catches ~3 in 4 errors; units held-out 36 % vs 10 %.
